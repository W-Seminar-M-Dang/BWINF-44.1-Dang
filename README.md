## Ausführen von .py-Dateien aus dem Terminal
Die Ausführung aus dem Computer-Terminal erfolgt so, dass man sich erst im Verzeichnis des Pro-
gramms befinden muss. Dies wird durch den Befehl *cd <Pfad>* erreicht. Das gewünschte Programm wird durch den Befehl python <AufgabeX.py> <ein-
gabedatei.txt> gestartet. eingabedatei.txt wird dabei mit dem Pfad der Datei ersetzt, die als Eingabe gewünscht wird. Man soll darauf achten, dass
der Python-Interpreter sich im PATH befindet
