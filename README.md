## Ausführen von .py-Dateien aus dem Terminal
Die Ausführung aus dem Computer-Terminal erfolgt so, dass man sich erst im Verzeichnis des Programms befinden muss. Dies wird durch den Befehl *cd <Pfad>* erreicht.
Das gewünschte Programm wird durch den Befehl python <AufgabeX.py> <eingabedatei.txt> gestartet.
eingabedatei.txt wird dabei mit dem Pfad der Datei ersetzt, die als Eingabe gewünscht wird, AufgabeX.py hingegen mit dem Pfad des Programms.
Es ist zu achten, dass der Python-Interpreter sich im PATH befindet. Je nach Betriebssystem kann auch python3 gefordert werden.

## Ausführen des Rust-Projekts von Yan Amin
Zum ausführen des Programmes von Junioraufgabe 1, öffnet man im Terminal den Pfad nach „Aufgabe2_Yan_Amin_Rust/program“.
Mit „cargo run --release“ wird der Code kompiliert und ausgeführt. Dafür wird aber die Rust toolchain, welche man unter https://rustup.rs/ installieren kann.
Das geht für Windows, Mac und Linux.
